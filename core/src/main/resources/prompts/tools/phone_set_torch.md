Turn the phone's flashlight (camera torch — đèn pin) on or off directly through the camera service: one call, no screens, no settings pages, nothing else opens. Use this tool for every flashlight request (bật đèn pin, tắt đèn pin, turn the flashlight or torch on/off) — never open quick settings or the camera app for the flashlight, and never explore services, processes, broadcasts or shell commands (dumpsys, service, cmd) to work the flashlight. on=true lights it, on=false turns it off; the result reports the state after the call (state) — once it matches what the user asked, stop and confirm. If it returns no_flash, this phone has no flashlight. If it returns camera_in_use or torch_unavailable, the flash is busy just now (the camera app may be open): only then fall back to the quick-settings flashlight tile.
